# held_out 目录：当前不可用（unavailable）

本目录按 `docs/product-upgrade/P0/eval-protocol.md` §6 的隔离规则预留。当前**没有独立采集的 held-out 数据**，因此任何评测输出中 held-out 部分必须记为 `unavailable`，不得以开发集改名、同义改写或已调试用例冒充盲测成绩。

采集规则（未来填充时必须遵守）：

- 按**来源材料、场景模板或药物组合**分组，同一分组不得横跨 dev 与 held_out；
- 禁止将开发中调试过的用例改名或微调后放入本目录；
- held-out 一旦用于选型/调参，其结果降级为开发评测，最终验证需另采新数据；
- 每个任务文件需在 `provenance` 字段记录来源与采集方式；
- 无专业评审时，质量指标限定为工程标注口径。

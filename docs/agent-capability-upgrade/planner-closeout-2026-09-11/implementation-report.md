## 真实失败后的最后调整

1. `arguments` 过去只有 `type: object`。最后补齐当前工具实际定义的嵌套属性、参数说明和必填 arguments/tool；合并共享参数时不把 memory_read 的 query 枚举错误施加给 rag_search。未自动生成模型缺失的检索 query，安全校验未放松。**最终 schema 的在线有效性尚未验证。**
2. 本批限流重试曾耗尽有限调用额度，未证明稳定性收益。因此产品默认 `PLANNER_PROVIDER_RETRIES=0`，仍可显式设为 1；冻结在线入口继续固定为 1，便于复现原协议，不能将其结果宣称为默认 0 的效果。
3. 页面排队期间 404 已修复，等待不再误标完成。最终前端构建与真实浏览器验证均针对这项修复之后的代码。

原协议的 SHA 未修改。本批源码指纹保存在在线 manifest；最终源码指纹保存在 `final-code/engineering.json`。二者不同是因为上述最后调整，不能把本批在线记录冒充最终源码的再次在线结果。
